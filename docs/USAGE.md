# 影梭·独立版使用说明

## 安装前

- 支持 Android 8.1 及以上。
- 默认需要网络加载高德在线道路图/卫星图，也可切换 CARTO / OpenStreetMap / Esri；地址搜索使用 Nominatim / Photon。
- 不需要 Root；需要手动指定系统的“模拟位置信息应用”。
- 本应用与原影梭包名、签名不同，可以共存。不要同时让两个应用争用模拟定位。

## 首次配置

1. 安装并打开 **影梭·独立版**。
2. 阅读并同意开发测试用途声明。
3. 允许定位权限；通知权限用于显示持续模拟状态和停止按钮。
4. 在系统设置中打开开发者选项。
5. 找到“选择模拟位置信息应用 / 模拟位置应用”，选择 **影梭·独立版**。
6. 若要使用悬浮摇杆，允许“显示在其他应用上层 / 悬浮窗”。

主界面和设置页都有独立的 **“权限设置”** 按钮。进入后可查看定位、模拟位置、通知、悬浮窗和系统定位服务状态：

- 点击 **“逐项开启（自动跳转）”**，应用会依次打开定位、后台定位、模拟位置、通知、悬浮窗、系统定位和电池优化界面；每完成一步并返回，自动继续下一项。
- 点击 **“系统应用权限页”**，直接进入本应用的系统详情页，可手动管理全部运行时权限。
- 模拟位置应用无法被第三方应用一键强制授权，仍需你在开发者选项中手动选择本应用。
- 某项被拒绝或跳过后，返回权限中心可看到未完成状态，可单独点击该项重新设置。

不同厂商菜单名称可能不同。

## 基本操作

- **地图选点**：点击“点击地图设置位置”，再点击地图。
- **更新地图数据**：普通图默认使用高德在线道路图，高德模式下卫星图使用高德在线影像；点击“普通图源”可切换 CARTO、OSM 德国镜像、OSM 官方在线或 Esri；点击“清除缓存并刷新在线地图”会绕过旧缓存重新请求瓦片。高德选点自动进行 WGS84 ↔ GCJ-02 转换，其他普通图按 WGS84 选点。
- **位置对不上**：先确认没有混用 WGS84、GCJ-02 和 BD-09，再切换图源核对。卫星影像有拍摄日期，道路底图也可能更新滞后，不能把影像日期当作实时地图版本。
- **搜索**：输入地名，选择搜索结果。搜索返回 WGS84 坐标。
- **输入坐标**：直接填写经纬度，可查看 WGS84 与 BD-09。
- **开始/停止**：主按钮调用后台模拟服务；通知栏也可停止。
- **摇杆**：开始后拖动方向盘持续移动，松手停止；选择步行、跑步或骑行速度。
- **历史/收藏**：保存最近使用位置，可再次使用、收藏或删除。
- **真实当前位置**：请先停止模拟再点击“更新当前位置”，避免把本应用的模拟 Provider 位置误当成真实设备位置。
- **复制/分享**：复制坐标或将位置链接发送给其他应用。

## 设置项

- 步行默认 1.2 m/s，跑步默认 3.6 m/s，骑行默认 10.0 m/s。
- 海拔默认 55 m。
- 随机偏移仅在使用历史/收藏位置时应用一次，不会在每次上报时乱跳；普通地图、搜索和手动输入不偏移。
- 历史记录默认保留 7 天，最多保存最近 100 条。

## 常见问题

### 提示没有模拟位置权限

重新进入开发者选项，将模拟位置信息应用设为本应用，然后彻底停止旧模拟并重新启动。仅授予普通定位权限不等于授予模拟位置权限。

### 位置闪回真实位置

这是 Android 调试 Provider 与融合定位并存时的常见现象。可尝试开启设备定位、关闭 Wi-Fi/蓝牙扫描、改用仅设备定位模式，并保持前台服务运行。效果因系统与厂商而异，不能保证所有设备一致。

### 某个 App 不显示模拟位置或提示 GPS 信号弱

先打开应用内的 **“定位诊断”**，检查模拟服务是否运行、最后成功上报时间、Provider 列表和错误/回退原因，并允许后台定位与忽略电池优化。

本版始终显式启用测试 Provider，并在系统支持时增加 Fused/Passive 兼容上报；不支持的兼容 Provider 会回退 GPS/NETWORK。

“GPS 信号弱”也可能来自硬件 GNSS 状态。公开 Android API 可以模拟普通 Location，但不能向其他 App 注入 GnssStatus、卫星数量或信噪比。`satellites=7` 只是 Location 附加字段，不代表硬件 GPS 信号。若目标 App 强制要求真实卫星状态或进行反模拟检测，无 Root 应用无法保证有效。

诊断页可复制结果。进一步排查时需要手机型号、Android 版本、目标 App 名称和诊断文本。

### 地图或搜索不可用

检查网络与系统时间。普通地图默认使用高德在线道路图，可切换 CARTO 或 OpenStreetMap；卫星图在高德模式下使用高德影像，其他模式使用 Esri；搜索优先 Nominatim，失败时切换 Photon。服务限流或离线时会影响使用；核心模拟服务本身不需要账号或私有 API Key。

### 停止与卸载

优先在应用或通知栏点击“停止模拟”，再卸载。停止后应用会移除自己注册的 GPS/NETWORK 测试 Provider。

## 边界

功能重建针对定位、搜索、历史、坐标输入和摇杆等行为；地图供应商、POI 数据、UI 视觉、原应用在线更新不与原包相同。
