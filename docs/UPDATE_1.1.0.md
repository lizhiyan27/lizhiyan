# 1.1.0 地图与权限更新

## 地图更新

Maven Central 当前列出的 osmdroid-android 最新稳定版仍为 **6.1.20**，原构建已经使用该版本，因此本次没有通过虚增依赖版本号来假装升级：

https://repo1.maven.org/maven2/org/osmdroid/osmdroid-android/maven-metadata.xml

本次实际修改的是在线数据来源和缓存策略：

- 默认普通图改为 **CARTO Voyager** 在线瓦片，数据来自 OpenStreetMap。
- 可切换 **OSM 德国镜像**、**OSM 官方在线**。
- 保留 **Esri World Imagery** 卫星图。
- 新增“清除缓存并刷新在线地图”：清理 osmdroid 当前缓存，并将瓦片过期时间设为立即过期，重新请求在线数据。
- 普通图源和地图类型均持久化保存。
- 新图源使用独立缓存名称，避免继续读取 1.0.0 的旧瓦片缓存。

当前桌面网络实测：CARTO Voyager 和 OSM 德国镜像可用；OSM 官方域名、OSM 法国和 Wikimedia 端点在当前网络不可用。应用保留官方源供其他网络环境手动选择，不承诺公共服务永久可用。

## 为什么“位置对不上”不一定是地图版本旧

1. **坐标系不同**：WGS84、GCJ-02、BD-09 不应直接混用。本应用内部保存 WGS84，BD-09 只在输入/显示时转换。
2. **底图更新延迟**：在线 OSM 数据也可能晚于现实道路变化。
3. **卫星影像拍摄日期**：卫星图通常不是实时影像，不能用拍摄日期判断定位是否准确。
4. **缓存旧瓦片**：可使用“清除缓存并刷新在线地图”强制重新请求。
5. **模拟位置与真实位置混淆**：获取真实当前位置前应先停止模拟。

因此，本次提供的是在线数据更新、图源切换、缓存刷新和坐标系提示，不能保证所有地点与某一商业地图完全重合。

## 权限设置中心

新增独立 `PermissionsActivity`，集中显示：

- 定位运行时权限。
- 模拟位置应用 AppOps 状态。
- Android 13+ 通知权限。
- 悬浮窗权限（仅摇杆需要）。
- 系统定位服务状态。

主界面点击“权限设置（逐项自动跳转）”会直接启动流程；设置页入口只打开清单。

流程：定位权限 → 模拟位置应用 → 通知权限 → 悬浮窗 → 系统定位服务 → 系统应用详情页。返回后自动继续下一项，最后在本页显示未完成项目，也可以单独重新设置。

“系统应用权限页”可直接进入本应用的系统详情页，手动管理全部运行时权限。

Android 没有允许第三方应用一键强制授予上述全部权限的公开 API，尤其是“选择模拟位置信息应用”和悬浮窗，必须由用户在系统界面确认。本实现自动完成跳转和返回衔接，不伪造授权结果。
