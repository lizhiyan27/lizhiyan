# 原影梭与独立实现功能对照

| 原功能 | 独立实现 | 说明 |
|---|---|---|
| 地图点击选点 | 已实现 | osmdroid + OpenStreetMap 德国镜像，替代百度地图 |
| 普通图 / 卫星图 | 已实现 | 默认高德在线道路图/卫星图，自动转换 GCJ-02；可切换 CARTO、OSM 和 Esri；支持清缓存刷新 |
| 地图缩放、拖动、标记 | 已实现 | 原生手势与内置缩放 |
| 返回当前位置 | 已实现 | Android LocationManager，读取最近位置并请求单次更新 |
| 地址关键词搜索 | 已实现 | Nominatim 优先，Photon 备用 |
| 搜索关键词历史 | 已实现 | 最近 20 条、去重、点击重用、可清空 |
| 直接输入坐标 | 已实现 | 输入时可选 WGS84 / BD-09，范围校验 |
| BD-09 显示与转换 | 已实现 | 内部统一 WGS84，仅输入/显示时转换一次；境外不施加 GCJ-02 偏移 |
| GPS 模拟定位 | 已实现 | `addTestProvider` + `setTestProviderLocation` |
| NETWORK 模拟定位 | 已实现 | 与 GPS 独立 Location，100 ms 周期 |
| Fused / Passive 兼容 | 已实现 | 系统支持时增加上报，失败自动回退 GPS/NETWORK；始终显式启用测试 Provider |
| 定位诊断 | 已实现 | 显示上报时间、Provider、错误、后台权限与硬件 GNSS 状态，不伪造卫星信号 |
| 海拔、方向、速度、时间 | 已实现 | 保留原字段及 GPS satellites=7 |
| 前台持续服务 | 已实现 | 定位类型前台服务 + 唤醒锁 |
| 悬浮摇杆 | 已实现 | 系统 WindowManager，无 Root |
| 圆形 / 按键摇杆 | 已实现 | 设置页切换 |
| 步行 / 跑步 / 骑行 | 已实现 | 默认 1.2 / 3.6 / 10.0 m/s |
| 显示 / 隐藏摇杆 | 已实现 | 悬浮窗关闭按钮及通知栏操作 |
| 通知停止模拟 | 已实现 | 通知栏直接停止并移除测试 Provider |
| 历史位置 | 已实现 | 本机 SharedPreferences JSON，最多 100 条 |
| 收藏、重命名、删除、清空 | 已实现 | 长按条目操作 |
| 历史有效期 | 已实现 | 默认 7 天 |
| 历史位置随机偏移 | 已实现 | 仅使用历史/收藏位置时偏移一次 |
| 位置复制与分享 | 已实现 | 剪贴板与 Android ACTION_SEND |
| 开发者选项指引 | 已实现 | 主界面与设置页均可进入 |
| 集中权限设置 | 已实现 | 独立权限中心显示状态，逐项自动跳转；也可直达系统应用权限页 |
| 用户协议与用途提示 | 已实现 | 首次启动确认，设置页可重读 |
| 原应用在线检查更新 | 不复制 | 避免私有更新渠道；源码构建即交付 |
| 作者联系/反馈页面 | 不复制 | 非核心定位功能 |
| 百度地图 POI 与视觉样式 | 不相同 | 数据供应商与 UI 不同，不能声称像素/数据一致 |
| 原 applicationId / 签名 / 百度 AK | 不复制 | 新应用可独立安装、与原包共存 |

核心定位、坐标输入、搜索、历史、收藏、分享和摇杆行为均已覆盖；“功能一致”不代表地图数据、在线更新或界面像素完全相同。
